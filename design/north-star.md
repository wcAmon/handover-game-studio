# 北極星草案 — Swarm-Agent

> 狀態：待人類審閱，尚未核准。既有選擇與新增提案分開標示；核准後鎖定，量產期不得自行修改。本文件的首版完成定義僅涵蓋沙漠一關，六區是完整遊戲方向。

## 一句話
玩家化身縮小的科學家，在明亮溫暖、植物覆蓋的古代科技世界中跑跳射擊、探索開路並恢復運輸，享受容易上手的冒險與突破防線的爽快感。

## 已確認的設計支柱
1. **火力闖關＋探索互動**：戰鬥之間探索支路、操作機關並改變路線；機關與卡車補給讓探索產生實際回報。
2. **機械與自然轉譯人體世界**：古代科技、灌木道路、巨型樹屋、活塞引擎、明亮天空；不出現器官、細胞、血肉或解剖外形。植物是健康世界的常態。
3. **中低難度，鼓勵重試**：倒下回最近檢查點並恢復生命，保留已開機關，不限次數；首版不以全程護送增加壓力。
4. **先完成一段完整體驗**：首版一位科學家、一把主武器、沙漠一關約 5–10 分鐘，具備起點、探索、機關、關底戰鬥與結尾。

## 核心循環
```mermaid
flowchart LR
  A[前進與觀察] --> B[跑跳瞄準射擊]
  B --> C[清除封鎖]
  C --> D[探索支路與開啟機關]
  D --> E[道路恢復與卡車補給]
  E --> A
```
- 30 秒：前進、辨認威脅、瞄準射擊、跳躍或利用地形。
- 數分鐘：穿越遭遇、選擇支路、啟動開路機關，讓運輸恢復並取得補給。
- 首版一次通關：穿過日曜沙道、完成關底戰鬥，收到下一區伏筆。5–10 分鐘是正常探索通關目標，不包含反覆失敗時間。
- 上述節奏為對已確認玩法的設計整理；不是已完成的遊玩測量。

## 首版規則（已確認）
- 四足防衛機器人會把玩家當入侵者；射擊使其停機，留下機械殘骸。首版不加入解除警戒機制。
- 恐龍、猛瑪象等生物是感染者的可見形象，不畫成微生物。首版具體動物編成由 blueprint 在沙漠範圍內設計。
- 三輪小卡車是運輸與補給單位：玩家清路、開橋後恢復通行並提供補給，不要求全程護送，也不是可操控載具。
- 玩家倒下回最近檢查點、恢復生命；已開機關保留，不限次重試。
- 本輪的檢查點承諾限本次遊玩中的重試；關閉頁面後的存檔尚未承諾。

## 世界觀、六區與敘事
故事中科學家縮小進入患者體內，但玩家看到的是古代科技與自然交織的完整世界。白血球為四足機器人、紅血球為三輪貨車、血管為灌木道路、腎臟為巨型樹屋、心臟為活塞引擎。

已確認的六區順序：
1. 日曜沙道：沙漠古道。
2. 碧潮港灣：海灘與碼頭。
3. 萬枝樹屋：巨樹與水循環設施。
4. 赤陶花城：城市、屋頂花園與交通橋。
5. 金輪高原：草原與巨型活塞引擎。
6. 雲冠中樞：代表腦部的雲端城市，奈米機器人 Swarm 位於中央核心。

完整旅程逐步揭露：動物入侵並非根源，Swarm 操控了防衛系統。最終清除 Swarm、取得破解源碼，留下其起源懸念。這是虛構世界觀。

**已確認輕量敘事**：開場幾句任務簡報，途中透過環境與簡短通訊帶出線索，沙漠結尾留下海灘港灣伏筆；不以長篇對話中斷射擊探索。

## 首版反目標
已確認：不一次製作六區、不做角色切換、不做駕駛或全程護送、不做解除警戒、不採陰暗潮濕 cyberpunk 或器官造型。

**新增提案，待本次審閱**：首版不加入多人連線、帳號後端、技能樹、裝備養成、程序生成或跨次遊玩存檔；不以手機／手把支援作首版驗收條件。成長回報先集中在路線打通、補給與關卡推進。

## 完成的定義
以下驗收清單待本次整體核准；勾選只可在實作並取得證據後進行。

### 由已確認內容整理
- [ ] 在電腦瀏覽器由開始畫面進入沙漠，完成關底戰鬥並看到通關與下一區伏筆；可重新開始。
- [ ] 一位固定科學家、一把主武器；A／D、空白、滑鼠、左鍵、E 依上表運作。
- [ ] 正常探索通關約 5–10 分鐘，保留實測路線與時間，不以等待或重試硬湊時長。
- [ ] 有可選探索支路、開路機關、道路恢復及三輪貨車補給，且能完整走通主線。
- [ ] 四足機器人可被射擊停機並留下殘骸；首版入侵動物有可辨識的戰鬥行為。
- [ ] 實測倒下後生命恢復、重生於最近檢查點，已開機關保持開啟；可連續重試。
- [ ] 有開場簡報、途中簡短線索與結尾伏筆，避免長對話強制中斷。
- [ ] 保存實機截圖，對照 004、005、007 檢查暖色、植物、機械造型、側視可讀性及無解剖外形。

### 新增提案，待本次審閱
- [ ] 最少一條可選支路、一組開路機關、起點之外一個檢查點、一場關底戰鬥；支路未探索仍可通關。
- [ ] 中低難度具體化：攻擊前有清楚預兆；教學起段最多兩個敵人同時參戰；受傷後提供短暫保護，避免一次碰撞連續扣血。參數於實測調整。
- [ ] 基本射擊、命中、受傷、機關與補給音效；一段輕快冒險背景音樂；可靜音，無須配音。
- [ ] 首版以桌面 Chrome 驗證，1280×720 視窗；代表性 60 秒戰鬥段目標平均至少 55 FPS，記錄測試機型與瀏覽器版本，不宣稱適用所有電腦。
- [ ] 暫停／恢復與失焦處理可靠，不出現卡鍵、重生後卡牆、機關開啟後無法前進等阻斷問題；暫停鍵提案為 Esc。
- [ ] 建立可重現的啟動、測試與截圖指令，關鍵戰鬥及重生狀態有驗證；交班檢查通過並提交版本。
