# Swarm-Agent — 六區旅程場景提案

2026-09-27。設計階段，未實作；人類已確認六區與行進順序；具體互動和戰鬥細節仍為提案，首版範圍已確認為沙漠一關，約 5–10 分鐘，中低難度。

## 已確認
- 優先平台：電腦瀏覽器，鍵盤滑鼠；A／D 移動、空白鍵跳躍、滑鼠瞄準、左鍵射擊、E 互動。
- 首版：日曜沙道一關，約 5–10 分鐘，中低難度，含探索支路、機關與關底戰鬥。
- 六區順序：日曜沙道 → 碧潮港灣 → 萬枝樹屋 → 赤陶花城 → 金輪高原 → 雲冠中樞。
- 核心玩法 A＋C：火力闖關結合探索互動。
- 先設計數個環境差異明顯的場景。
- 最後一關在腦部，以雲端城市呈現，奈米機器人位於核心。
- 沿用已確認的古代科技＋植物、明亮溫暖方向，完全不畫器官或細胞。

## 首版交戰規則
- 首版四足防衛機器人可被射擊至停機，停機後留下機械殘骸；不加入解除警戒機制。
- 停機的殘骸必須有清楚視覺差異，不再被誤認為正在攻擊的敵人。

## 探索與射擊如何結合
提案原則：一段交火 → 發現設施或分支 → 短互動改變路線／戰場 → 下一段交火。
- 主路始終可辨識；支路有補給、捷徑或劇情線索，不要求全收集才能過關。
- 每區只突出一種環境互動，再把前面學過的互動帶到後段；避免六區各長出一套複雜系統。
- 探索是可讀的路線選擇與機械互動，暫不設計長時間解謎或全圖往返。
- 每區的最終遭遇先保留設計空間，不預設每區都需要獨立大型 Boss。
- 首版沙漠目標時長 5–10 分鐘；探索比例待定。
- 首版三輪小卡車為運輸與補給單位；玩家清路、開橋後恢復通行並提供補給，不要求全程護送，不作為可搭乘操控的載具。
- 已確認重試規則：角色倒下後回到最近檢查點、恢復生命，保留已開啟機關，不限次重試。 檢查點配置與敵人重置細節待設計。

## 世界對應與敘事邊界
- 灌木道路與三輪貨車是跨區共通的交通系統；不是每個場景都要長得像公路。
- 第 3 區巨型樹屋對應腎臟；第 5 區活塞引擎對應心臟；第 6 區雲端城市對應腦部。
- 前兩區及赤陶花城暫不強行指派額外器官，避免自行增加未核准生理對照。
- 006 海灘引擎圖仍是已核准的美術參考；已確認的六區順序把主要引擎關放在高原，以增加地貌差異。
- 前段的生物入侵像是主因；中段異常防衛命令提示更深層操控；最後揭露核心 Swarm。生理與醫學描述作為虛構故事設定，不當作教育事實。
- Swarm 使用精密、小型、幾何機械外形；與象牙色大型四足防衛機器人區分。圖 009 的前景機器刻意放大以讀清造型，非絕對尺度圖。
