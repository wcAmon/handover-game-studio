# 概念圖：先有圖，再談設計

人類是視覺動物。你的工作是**用圖片把模糊的點子變成具體、可指認的選項**，讓後續所有討論都能說「像這張」而不是「感覺溫暖一點」。

## 工具

```bash
python3 tools/imagegen.py --prompt "..." --slug harbor-pixel --round 1 --note "方向 A：像素"
python3 tools/concept_board.py        # 重新生成 design/concept/board.html
```

- 圖存到 `design/concept/NNN-slug.png`，同名 `.json` 記錄 prompt、模型、輪次、備註。
- 需要 `OPENAI_API_KEY`（gpt-image）或 `GEMINI_API_KEY`（Gemini image）；兩者都沒有時，停下來請使用者設定。
- 生完圖**一定要自己讀圖**（Read 圖檔）確認內容，再給使用者看。生圖模型常常不照 prompt 畫；不符合就修 prompt 重生，不要把錯的圖端上桌。
- 每輪結束後生成看板，告訴使用者打開 `design/concept/board.html`（或直接列出圖檔路徑）。

## 流程

### 第 0 步：一句話點子
若使用者還沒給點子，只問一題：「用一句話描述你想做的遊戲（可以很模糊）」。

### 第 1 輪：發散（3-4 張）
- 挑一個**最能代表遊戲的場景**，用**不同美術方向**各畫一張（例：像素、低多邊形 3D、手繪水彩、平面向量、版畫/墨線）。**同場景不同風格**，才能讓使用者比較風格而不是內容。
- 方向要真的不同，其中至少一個是使用者不太可能自己想到的。
- 給每張圖一個代號（A/B/C/D）與一句話描述它傳達的感覺。
- 問使用者：哪張最接近？想混搭哪些元素？有沒有全部都不對的地方？

### 第 2 輪：收斂（4 張，依使用者選擇的方向）
1. **主視覺 key art** — 遊戲的情緒與世界觀
2. **角色 / 主要物件設定** — 玩家操控的東西長什麼樣
3. **環境 / 關卡氛圍** — 玩家大部分時間待在哪
4. **假遊戲截圖** — 含鏡頭角度、HUD、玩家角色在畫面中的大小。**這是最重要的一張**：它逼出鏡頭、操作、畫面資訊密度等玩法問題。

每張圖都搭配 1-2 個討論問題，把話題從視覺延伸到設計：
- 假截圖：「這個俯視角代表玩家主要是在規劃路線，而不是反應操作 —— 對嗎？」
- 環境：「這座城市為什麼沉沒？玩家需要知道嗎？」
- 角色：「玩家是這個角色，還是在操控這個角色？」

依回饋再迭代，直到使用者說「對，就是這種感覺」。

### 第 3 輪：鎖定
用 `templates/style-guide.md` 寫 `design/style-guide.md`：
- 定案圖的清單（北極星參考圖）
- 色票（從圖中擷取的 5-8 個 hex 值）、形狀語言、線條、光影、材質
- 鏡頭與畫面構成規則
- **Prompt 配方**：一段可以直接當前綴的風格描述 + 負面描述，讓量產期生成的素材保持一致
- 討論中順帶浮現的玩法、環境、故事想法 → 記在「待拷問」清單，交給 `/grill`

## 結束

總結定案的方向與圖檔，然後建議使用者接著執行 `/grill`。
